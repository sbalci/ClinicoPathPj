CCC Complete Measurement Pairs

Lin CCC describes concordance between two measurements in the same units on each independent case. Pearson correlation describes precision; bias correction describes departure from the identity relationship. CCC depends on case mix and does not replace a differences-based agreement assessment. Missing measurements are excluded as pairs. Case-ID checks identify known repeated IDs but cannot prove independence or common units. At least 10 complete pairs are required. This partial core provides point estimates only: no confidence intervals, hypothesis tests, clinical acceptance bands, outlier deletion, imputation or repeated-case inference. The measurement plot shows the retained raw pairs without fitting a model.
