Cases must be independent and scores measured on the same cases. DeLong uncertainty is a large-sample normal approximation; small classes can have materially inadequate coverage. The minimum of two observations per class only permits variance calculation and does not establish reliable inference. Comparisons are unadjusted for multiple testing. Scores are analyzed as supplied, without fitting, calibration or clinical acceptance bands. Bootstrap, partial/smoothed/multiclass ROC, cutoff optimization and interactive exploration are not implemented in this core.
